**Java Basic Projects 2025**

Repository ini berisi kumpulan project pembelajaran **Java dasar** yang dibuat sebagai tugas sekolah menggunakan **NetBeans IDE**.

🎯 Tujuan Project
Mempelajari dan memahami konsep dasar pemrograman Java secara bertahap, mulai dari logika dasar hingga pemrograman berorientasi objek.

🛠️ Teknologi yang Digunakan
- Bahasa Pemrograman: Java  
- IDE: NetBeans  
- Platform: Desktop  

📂 Daftar Materi Project
- **Data Statis dan Dinamis** 
  Program Java yang membahas penggunaan data tetap dan input dinamis.

- **Percabangan**  
  Implementasi logika percabangan menggunakan `if`, `else`, dan `switch`.

- **Perulangan**  
  Penerapan struktur perulangan `for`, `while`, dan `do-while`.

- **PBO (Pemrograman Berorientasi Objek)**  
  Penggunaan class, object, method, dan encapsulation.

- **Modifier**  
  Pembahasan access modifier seperti `public`, `private`, dan `protected`.

- **Praktek**  
  Kumpulan latihan dan implementasi dari materi yang telah dipelajari.

▶️ Cara Menjalankan Project
1. Download file zip, jangan lupa Exstrak terlebih dahulu
2. Buka folder project menggunakan NetBeans/VsCode
3. Pilih salah satu folder materi
4. Jalankan file `.java` yang tersedia
